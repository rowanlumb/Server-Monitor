Server Monitor

A standalone device meant to sit on your desk. The monitor connects to your local router and reads your local server status, uptime, wifi, database latency, and more. Alerting you if anything goes down.

  • Project Type Server Monitoring
  • CAD Autodesk Fusion
  • Microcontroller ESP32-S3-DevkitC-1
  • Display TFT
  • Server Interface Flask API Endpoint
  • Author Rowan Lumb
  • Status In Progress
