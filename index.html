Server Monitor

A standalone device meant to sit on your desk. The monitor connects to your local router and reads your local server status, uptime, wifi, database latency, and more. Alerting you if anything goes down.

  • Project Type Server Monitoring
  • CAD Autodesk Fusion
  • Microcontroller ESP32-S3-DevkitC-1
  • Display ESP32-TFT Display
  • Server Interface Flask API Endpoint
  • Author Rowan Lumb
  • Status In Progress

Comments & Lessons

  • I used a snap fit on the bottom which is working nicely, but glued the bottom and top sections, but would like to use either magnets, screws, or snap fit for a 3d version.
  • I would probably reduce small around the display if I do another version, but at the same time that space provides alot of relief for the wiring.
  • Originally had some very small M1.7 brass heat insets but had some issues inserting them into the PETG plastic so will switch to designed fit or magnets so switched to snap fit for bottom.
